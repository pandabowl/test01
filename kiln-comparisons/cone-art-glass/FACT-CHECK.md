# Cone Art glass kilns: fact-check

Pages: the `cone-art-glass` shared block (`../cone-art/blocks/cone-art-glass.html`)
is listed in `custom.comparison_blocks` on the main Cone Art page
(`tucker-s-cone-art-kilns`) and on
https://www.sheffield-pottery.com/collections/cone-art-glass-fusing-kilns.
Live since 2026-11-19; see `../cone-art/PUBLISHED.md`.

## What matched Cone Art

Interior sizes, amps at 240V/208V, breaker sizes, hardwired 8' cord on
240/208V models, 117G NEMA 5-15P and 115G SQ NEMA 5-20P plugs on 6' cords,
lid elements, CSA/cUL, B3K = Bartlett 3-button and V6 = V6-CF, lid lifter
optional on the 23 and 28 series and now included on the 42 series.

## Cone Art's own sources disagree, or don't add up

- Sections: the catalog lists 2 sections for every 13.5"-deep model; the newer
  price list lists 1 for all. Not shown on the page. The store says 1, which
  matches the price list.
- Capacity: both Cone Art documents give cu ft figures that don't fit their own
  interior sizes for three models, so the glass table has no capacity column.
  Ask Cone Art before changing the store's numbers:
  - 117G: Cone Art 1 cu ft; 14.5" x 6" works out to about 0.6. Store: 0.69.
  - 2309G SQ: Cone Art 2.3; 23" x 23" x 9" = 2.76. Store: 2.8.
  - 2313G SQ: Cone Art 3.45; 23" x 23" x 13.5" = 4.1. Store: 4.2.
- Max temperature: neither document gives one for glass kilns, so the table
  has no max-temp column.

|---|---|---|---|
| 117G | spec table, inside | 14.5 x 6.5 | **14.5 x 6** |
| 2309G SQ, 2313G SQ | description | "Fires to 1700F" | no max temp published |
| 1809G, 1813G, 2309G, 2313G, 2309G SQ, 2809G, 2813G, 4209G, 4213G | description / finder note | "elements in lid and walls" | Cone Art lists **lid elements** only |
| 2813G, 4209G, 4213G | description / finder note | 3" brick walls | not in Cone Art's current documents |
| 4209G, 4213G | description | (no mention) | lid lifter now **included** on the 42 series |

## Errors in existing page content (not changed; for the user)
